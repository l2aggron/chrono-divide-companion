Stored maps ? Everything this machine is holding, whatever ladder it belongs to — a ladder tab lists that pool's maps and nothing else, so a map rendered from a match on anything else appears only here. Heaviest first, because the reason to open this tab is usually that storage is filling up. Overlay hotkeys

Click a key, then press the combination you want. A hotkey can be taken by the game, the browser or Windows — Alt+Shift is the Windows keyboard-layout switch, for instance, and never reaches the page.

Game commands

A key of yours that fires one of the game's own commands. The extension takes the press before the client sees it, which is what makes this the only way to move a command the client will not rebind: the alliance screen is stamped onto Tab every time the client loads its key table, and it is missing from the client's own keyboard options entirely.

Binding Tab here is therefore what frees it — a key this list claims never reaches the game. A Tab you have not bound goes on opening the alliance screen.

Build hotkeys

A key that queues one of something — the same order clicking its sidebar cameo sends, and nothing else: you still place a building yourself. The game has no build hotkeys of its own, so most of these will be keys it already uses for something; the extension takes the press first, and __cdc.build() in the game tab's console lists which of your bindings override a game command.

Bindings are per side, because the sides do not build the same things. A key bound to a unit your country cannot build stays inert and says so in the match rather than doing something else.

Build chords

The game already has keys for the four sidebar tabs — q w e r unless you have changed them. Press one twice, quickly and that tab opens as a grid under the cursor, laid out like the keys themselves: qwert on the top row, asdfg under it, zxcvb below. The next key orders that slot, Shift orders five of a unit, Ctrl puts one next, and Esc or a click outside closes it. Everything your country builds is drawn, with what cannot be ordered at this moment dimmed — or, with the box below ticked, only what you can order right now. A structures chord pressed while a building is finished picks that building up to place instead — its queue is full until you do, and the tab key does the same from an open grid, for the building that finished while you were watching it.

How many: a tap is one, Shift is five, and a key held down for about half a second fills the queue with as many as still fit. Alt turns any of the three into a cancel aimed at that slot — once to put its queue on hold, again to cancel; Alt+Shift for five, Alt held down for all of them. A tap has already acted before a hold counts, so nothing waits for the key to come back up.

Ctrl orders the slot next rather than last — the game's own Ctrl+click on a cameo. It goes in behind whatever is being built, which keeps its progress and its place: five Rhinos with a Ctrl'd Grizzly build one Rhino, then the Grizzly, then the other four. Ctrl+Shift inserts five and Ctrl held fills the queue behind the head. It does nothing on a buildings tab, whose queue holds one item at a time, and the same Ctrl on any of the fixed build keys below means the same thing.

The first press is still the game's own tab switch; nothing is taken from it. If you have rebound the tabs, the chords move with them.

Alt and a tab key stops what that tab is building, without opening anything: once to put the queue on hold, again to cancel it — the sidebar's own right click, on the item being paid for. A finished building cancels on the first press, having nothing left to pause. Alt+Shift cancels five at once, and pauses on the way if you had not already. Alt is the cancel everywhere: on a slot of an open grid it is that slot, with no grid open it is the tab's own queue.

A key whose building is a superweapon stops ordering once you have one — a second Chronosphere grants no second Chronosphere — and aims it instead, entering the same targeting mode the sidebar cameo does, so you still pick the target yourself. Those tiles show the charge where a queue's progress would be, and turn green when it is ready.

The two paradrops keep keys of their own, because the buildings behind them are not superweapon buildings: the American drop shares the Grand Cannon's key — one is French, the other American, so the key is dead for neither — and the drop off a captured tech airport is on g, the same key on both defence grids. That leaves the Airforce Command key building airfields, which is what it is for.

Ticked, a key still waiting on the tech tree is not drawn at all: a prerequisite that is not up, a factory you no longer have, a unit that only a spy in the enemy battle lab unlocks — it appears on its own key the moment it becomes buildable. Ticked, Alt+Enter does what Alt+F did and Alt+F does nothing on its own; the grid still takes it while a grid is open, which is the case this exists for. Unticked, Alt+F is the game's again everywhere except under an open grid, where it stays a cancel. Nothing here calls fullscreen itself — the game is handed its own key, so it keeps the keyboard lock it takes with it.

Taunts

The game has eight taunts and a key for each — F5 to F12 as it ships. A browser keeps the top of that range for itself: F11 is fullscreen and F12 is developer tools, and a page cannot take either back, so two of the eight cannot be pressed at all and the rest are a hand off the keyboard.

The key in the list above opens them as a grid under the cursor, laid out like the build chords — qwert on the top row, asdfg under it. A key sends that taunt and closes the grid; Esc or a click outside closes it without sending. Each tile carries what the taunt says, under a strip naming the country you drew and its flag — the eight lines are per country, so the same key means something else in the next match. Each tile also shows the key the game has on that taunt, and clicking it — or right-clicking the tile — listens for a new one and writes it into the game's own keyboard file, exactly as its Options → Keyboard screen would. That binding then works with nothing of ours open.

Two things worth knowing before you press one. A taunt is only ever sent to other players, so it does nothing in a match against the computer, and there is a five-second cooldown between them. And the sounds are the ones your own client imported — a country whose Taunts folder is empty sends the taunt anyway and hears nothing, which the grid marks by striking the name through.

The eight lines below are one country's — every country has its own set and there is no shared one. Pick a country to read what its taunts say; the layout you edit under them is the same layout whichever one is picked. A line too long for its tile is clipped, and hovering the tile shows the rest. The flag belongs to the game's own art and only the in-game overlay can draw it.

The ▶ on a tile plays that taunt. The sounds are the ones your own client imported and they live inside the game's own storage, which a settings page cannot open — so the first play asks a game tab for the file, and opens one if none is running. That first one can take a while: the client has to finish loading its game files before it can look, and the file itself is converted on the way — Red Alert 2 stores its taunts in a compressed form no browser will play, so the game tab runs them through the client's own decoder first.

If nothing plays, the line under the grid says which absence it is — no Taunts folder at all, or a folder without this country's file in it. Red Alert 2 keeps its taunts as loose .wav files in a Taunts folder beside the game, not inside a .mix, so an import taken from mix files alone has none of them. That is the client's state and not this page's: those taunts are silent in matches too, which is what a struck-through name in the in-game grid means.

Pick a key above to change which taunt is on it.

Save your settings ? The game keeps its hotkeys in a file inside the browser's own private storage, and the rest of its options in that browser's localStorage. Neither is a file you can find and copy. This reads both through a game tab — one is opened if none is listening — and writes them into a single file alongside the extension's own bindings.

Everything that defines your keyboard, in one file: the game's own hotkeys first, the extension's bindings next to them. Take it to another browser, load it there, and neither half has to be rebound by hand.

Load a backup

What the file holds is listed before anything is written. What was there before is kept, so Undo puts it back — and an import reloads the game tab where the client reads a setting only at start-up. The same tick boxes govern what is taken out of the file, so a backup holding everything can be loaded for its hotkeys alone.

The file itself

The same JSON, for when a file picker is in the way — a locked-down profile, a machine you are on through someone else's screen. Copy fills it from a read; paste one in and Read the box below instead takes it. The readable block in it is written for you and ignored on the way back in, so editing it changes nothing.

Log ? The last few hundred things the extension did, newest at the bottom: the game tab's narration of a render run, and every write to storage — attempted, then stored or failed. It survives the tab that made it, which nothing drawn over the game does.

Replays ? A ladder replay records every action both players took, so the build order is in the file — this page reads it without loading the game. Everything is shown where it happened: a structure is two rows, ordered and placed, and units are shown as the game accepted them into a queue, which holds 30 of a type. Clicks at a full queue are counted apart, under overclicks, because they are not units. Nor is an accepted order a delivery — it can still be cancelled, starved of credits or lost with its factory. What actually came out, when a building was ready to place, credits, kills and losses are not in a replay at all: Run the match plays it through in a game tab (a few seconds) and reads those off the simulation.
